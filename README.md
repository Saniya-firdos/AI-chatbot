# AI Chatbot

A terminal-based AI chatbot built using Python and the Google Gemini API.

This chatbot is designed to have warm and supportive conversations in Hinglish while maintaining conversation history throughout the session.

## Features

- AI-powered conversations using Google Gemini API
- Terminal-based chat interface
- Maintains conversation history
- Warm Hinglish conversational style
- Supportive and encouraging responses
- API key based authentication
- Built completely with Python

## Technologies Used

- Python
- Google Gemini API
- Google GenAI Python SDK
